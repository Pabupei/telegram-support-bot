# Telegram Support Bot

A Telegram customer support and ticket management bot built with Node.js and SQLite.

The bot allows users to create support tickets, select a category, track ticket status, and receive replies directly from an administrator.

## Features

- 🎫 Support ticket creation
- 📂 Ticket categories: Technical, Billing, General
- 👤 User ticket history
- 🔄 Ticket statuses: Open, In Progress, Closed
- 👨‍💼 Admin panel
- 📋 View and manage all tickets
- 💬 Reply directly to users
- 🔓 Reopen closed tickets
- 📊 Support statistics
- 🔔 Admin notifications for new tickets
- 💾 SQLite database storage
- 🔐 Environment variables for sensitive configuration

## Tech Stack

- JavaScript
- Node.js
- Telegram Bot API
- node-telegram-bot-api
- SQLite
- dotenv
